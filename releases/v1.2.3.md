# v1.2.3 — Jellyfin 12.0 兼容性修复

修复升级 Jellyfin 服务端到 12.0 后，`1.2.2-zh-hw` 无法获取媒体内容的问题。12.0 默认关闭旧鉴权，本版统一改用标准 `Authorization: MediaBrowser` 请求头，以及播放和字幕链接中的 `ApiKey` 参数。

- 覆盖登录、Quick Connect、首页、媒体库、搜索、封面、ExoPlayer / MPV、音乐和播放状态上报。
- 修复设备 ID 缺失时进度上报遗漏登录令牌的问题。
- 媒体库请求失败时保留已有数据，并显示登录或权限错误，避免只看到空白页面。
- 登录流程不再输出密码、Quick Connect secret 或登录令牌片段。
- 保留 Android 5.0 / API 21、原应用 ID、原发布签名和 ARM 分包，可覆盖安装。

构建版本：`1.2.3-zh-hw`（`10203`）。本地 30 项 JVM 测试通过，Lint 无错误和 `NewApi`，两个 APK 通过 API 21、ABI、v1 签名及原发布证书校验。隔离的官方 Jellyfin 12.0.0 实例通过 22 项 HTTP 检查，确认旧媒体库鉴权返回 401、新鉴权返回 200，以及视频流、字幕和进度接口正常。Android 5 真机播放仍需验证；具体边界见 `README-ANDROID5.md`。

安装包按设备系统架构选择：

- `elefin-release-armeabi-v7a.apk`：32 位 ARM 系统，适用于多数旧 Android 5 电视盒子。
- `elefin-release-arm64-v8a.apk`：64 位 ARM 系统。

可直接覆盖安装 `1.2.2-zh-hw`。升级后若提示登录失效，请退出账号并重新登录。
