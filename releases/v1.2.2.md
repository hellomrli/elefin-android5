面向 Android 5.0（API 21）电视和盒子的稳定性修复与性能优化。版本名为 `1.2.2-zh-hw`，版本号为 `10202`。

继续使用原应用 ID 和原发布签名，保留 v1 签名，支持旧版本覆盖更新并保留应用数据。

- 修复 MPV 初始化、前后台切换和销毁时的原生调用竞态，降低快速退出播放器时的崩溃风险。
- 修复退出后的进度上报、续播恢复和已看状态；转码与 MPV 回退保留当前播放位置和轨道选择。
- 修复电视剧库、搜索和详情路由中的协议类型，并校正 Jellyfin 查询字段与排序参数。
- 媒体库改为每页 60 项，排序、筛选和字母定位在服务端执行；推荐、发现和合集按需加载。
- 首页仅在前台刷新，复用网络连接、图片加载与取色缓存；限制低内存设备的图片和视频缓冲预算，减少后台轮询与不必要的图形内存分配。
- 根据设备解码能力选择播放方案；低内存设备使用更保守的 H.264 / AAC 转码回退配置。
- 恢复 MPV 的 HTTPS 证书校验，补齐中英文字幕备用字体及许可证。使用自签名 HTTPS 服务器时，需要在设备中信任 CA 并配置完整证书链。
- 固定 API 21 兼容依赖，云端发布前执行 JVM 回归测试、Lint，以及 APK 的版本、最低系统、ABI、字体资源和原签名检查。

下载时按设备支持的架构选择：

- `elefin-release-armeabi-v7a.apk`：支持 ARM 32 位应用的电视或盒子。
- `elefin-release-arm64-v8a.apk`：支持 ARM 64 位应用的电视或盒子。

本次尚未完成 Android 5 真机端到端验证，硬件解码、遥控器焦点、长时间播放和实际内存占用仍需在设备上确认。详细修复说明见仓库中的 `README-ANDROID5.md`。
